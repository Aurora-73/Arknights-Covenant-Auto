# 明日方舟 卫戍协议自动电表倒转

用于 **150远见 / 250奇迹** 后的电表倒转玩法：

- 自动买入**经济类干员**获取资金
- 资金足够后，买卖**获得时类干员**叠加盟约层数
- 校准时会记录待部署区当前的图像，后续**不会出售已位于待部署区的干员**

基于截图识别与模板匹配实现批量购买与出售的完整循环。

## 退出方式：直接按 `Win + D` 返回桌面即可退出

---

## 环境要求

### Python 版本

- Python 3.10 及以上

### 依赖包安装

```bash
pip install pyautogui pywin32 Pillow numpy scikit-image opencv-python ddddocr
```

| 包名 | 用途 |
|------|------|
| `pyautogui` | 屏幕截图与鼠标点击控制 |
| `pywin32` | Windows 窗口句柄操作（win32gui / win32api / win32con） |
| `Pillow` | 图像读取与预处理 |
| `numpy` | 图像数组运算 |
| `scikit-image` | SSIM 结构相似度计算 |
| `opencv-python` | 图像灰度转换 |
| `ddddocr` | OCR 数字识别（余额、售价） |

## 使用前准备

### 设置游戏窗口分辨率为 1280×720

脚本内所有坐标均基于 **1280×720** 分辨率校准。请在游戏设置中将窗口大小调整为该分辨率，否则坐标将发生偏移导致脚本无法正常工作。

> 游戏路径：`设置 → 画面 → 分辨率 → 1280×720（窗口模式）`

---

## 运行步骤

### 第一步：运行校准脚本，生成模板图片

```bash
python Calibrate.py
```

脚本启动后会等待 **3 秒**，请在此期间切换到游戏窗口并停留在**贸易站界面**。

校准脚本将自动完成以下操作：

- 截取**待部署区**当前图像并记录，后续运行时不会出售已在该区域的干员
- 截取 10 个出售槽位区域，保存为 `area0.png` ~ `area9.png`
- 循环识别售价数字（0 / 1 / 2 / 3），每找到一个新数字即保存为对应的 `0.png` / `1.png` / `2.png` / `3.png`
- 若当前页面未能覆盖全部数字，自动点击刷新继续扫描，直到 0~3 全部收集完毕

校准完成后，目录下应存在以下文件：

```
0.png  1.png  2.png  3.png
area0.png  area1.png  ...  area9.png
```

### 第二步：运行主程序

```bash
python Run.py
```

脚本启动后同样等待 **3 秒**，请切换至游戏**贸易站界面**。

程序将循环执行以下流程：

```
识别余额
  ├── 余额不足 → 买入经济类干员获取资金
  └── 余额充足 → 买卖获得时类干员叠加盟约层数
点击刷新
批量出售（跳过待部署区内已有的干员）
写入日志
```

## 文件说明

```
├── window_topmost.py  # 窗口置顶工具，确保游戏窗口在最前
├── Calibrate.py       # 校准脚本，首次使用时运行
├── Run.py             # 主程序，校准完成后运行
├── 0.png              # 售价数字模板（校准后生成）
├── 1.png
├── 2.png
├── 3.png
├── 4.png              # 空售价模板（不会自动生成，需手动提供）
├── area0.png          # 出售槽位模板（校准后生成）
├── ...
└── area9.png
```

---

## 注意事项

- 每次更新游戏或更换设备后，建议**重新运行校准脚本**以刷新模板。
- 脚本运行期间请勿移动或缩放游戏窗口。
- 若识别出现偏差，请确认游戏窗口分辨率是否仍为 **1280×720**。
- `4.png`（空售价模板）不会自动生成，需在游戏中手动截取空格子图像后命名保存。
- 日志默认写入网络路径，若路径不可用将自动回退至当前目录下的 `log.txt`。
